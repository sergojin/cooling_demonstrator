# Option A Optimization Archive

The pre-Option-B optimization work is intentionally left in place to avoid
moving large Condor output trees and breaking paths embedded in logs/scripts.

Primary archived workspaces:

- `../source_z2000`: original Horn Option A target/horn source sample.
- `../resample_test`: downstream resampling studies and diagnostics.
- `../chicane_group_scan`: chicane/decay-channel scans, validation jobs, and
  high-stat summaries.
- `../surrogate_opt`: surrogate-model proposal and plotting utilities.

New Horn Option B work should live under `../option_b`.
